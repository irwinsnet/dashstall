# Dashstall
The Dash tutorial's *Hello World* tutorial and Pyinstaller.

1. Run `uv sync` to build the virtual environment.
2. Activate the environment.
3. Use the `drun` command to run the Dash app from the virtual environment.
4. Build the PyInstaller executable by running the `pybuild.ps1` script.
5. Run the app from the PyInstaller installation by running dist/app/app.exe.
